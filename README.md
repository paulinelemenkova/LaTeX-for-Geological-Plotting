# LaTeX Figure Source — Using TeX Markup Language for 3D and 2D Geological Plotting

LaTeX (TikZ / pgfplots / tikz-3dplot) source code for the **figures** of the peer-reviewed article by Vasiliy Lemenkov and Polina Lemenkova.

**Published in:** *Foundations of Computing and Decision Sciences* **2021**, *46*(1), 43–69
**DOI:** https://doi.org/10.2478/fcds-2021-0004

## Contents
TeX source for the paper's graphics: 2D and 3D scatterplots, ternary diagrams, bar charts, boxplots, zoom/`spy` detail insets and a flowchart, built with the `tikz`, `tikz-3dplot`, `pgfplots`, `filecontents` and `spy` packages from geotechnical soil-laboratory data (CSV).

The LaTeX **manuscript (text)** source for this article is in a companion repository: https://github.com/paulinelemenkova/latex-geological-plotting

## Citation
Lemenkov, V.; Lemenkova, P. Using TeX Markup Language for 3D and 2D Geological Plotting. *Foundations of Computing and Decision Sciences* **2021**, *46*(1), 43–69. https://doi.org/10.2478/fcds-2021-0004
